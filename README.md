# Confirm-Address for Outlook.js

- Original by Meatian [Confirm-Address for Thunderbird](https://github.com/Meatian/confirm-address/)
- Outlook version ported by [Keiji Momose](https://github.com/beatkz/)

This Office Add-in confirms mail items before sending as follows:

- Mail addresses between insider and outsider
- Head of mail body
- Attached file name(s)

Due to its platform limit, this Office Add-in is only for Outlook (new) and Outlook on the Web(OWA).

If you wish to use on Outlook Classic, please use [Confirm-Address for Outlook Classic](https://github.com/beatkz/confirm-address-outlook/) instead.

To get started, please copy a link [manifest.json](https://beatkz.github.io/confirm-address-outlook-js/manifest.xml).
